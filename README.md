# Arura
An elegant and advanced Salla theme with modern features

## Features
- Responsive design optimized for all devices
- Advanced customization options
- Modern and clean interface
- RTL support
- Multi-currency support
- SEO optimized
- Fast loading performance
- Advanced product features (wishlist, compare, quick view)
- Social media integration
- Newsletter subscription
- Advanced search functionality

## Installation
1. Download the theme files
2. Upload to your Salla store
3. Configure theme settings in the customizer
4. Enjoy your new Arura theme!

## Customization
The theme includes extensive customization options:
- Color schemes
- Typography settings
- Layout options
- Header styles
- And much more...
